# 09 · 踩坑清单（15 条）

> 按"你会不会遇到"排，不是按严重性。
> 建议动手前通读一遍。**前 5 条最容易在 30 分钟内再踩一次。**

## 引擎理解类

### 1. 「Energy 省着更稳」——错得最彻底的一条
每季发 3 点，**当回合分配完、不累积、季度末清零**。省下来等于扔掉。
COR 原则 4 说的"资源必须投资才能积累"在这儿直接成立。
**记：每季能量花满换资本，这是铁律。**

### 2. 「只有 6 个维度」——实际有 9 个可见字段
多 `Level` / `Energy` / `CurrentLevelDuration`。设计早期按 6 个维度做，方案返工。

### 3. Output 不是终局分
O 计入状态、也影响绩效，**但不计入终局评分**。别按 "O 高 = 分高" 排优先级。

### 4. 报销 / 做平账不是财富收入
是**风险陷阱**（Risk +）。早期当成 W 来源，白高兴了半天。

### 5. 风险关键词的符号搞反
「风险增加」的词被误进 `_NEG` ⇒ 奖励里反而加雷。
**记：关键词表改完必须逐条复核一遍，别信"感觉"。**

## 数据 / 逆向类

### 6. 🔴 用错了数据集（最贵的一次）
用了 `career_emulator_bdci26/dev/dataset`（旧 dev），正式的是 `career_emulator/data/dataset`。
**后果：基于错误数据做的"真相版大改"整体作废。**
**记：逆向之前先确认数据源路径，这一条能省你三天。**

### 7. `stat_clamp` 是硬截断不是软上限
`cap = int(门槛 × 1.2)`，实战中常因 ContextVar 未传递而不生效。
一开始当软封顶用，后面才发现是 `int(...)` 硬切。

### 8. 「回血 2E」——SKILL 里 9 处一致，全是错的
文本自洽骗过了自己：**9 处写着同样的话，只说明我们复制粘贴了 9 次，不说明它对。**
只有回引擎原文才查出来。
**记：重复次数 ≠ 正确性。**

### 9. 「N 溢出是真浪费」——被数据证伪
N 是 S 动作的**免费副产品**且 score-neutral。8/28 据此改了一整版 SKILL，一天白跑。
**记：先做分来源分解再改策略。**

### 10. 判定时机理解错（这条最影响策略）
判定在 `M(W−1) → M(W)` 瞬间，**判定值 = W 月首帧观测**，不是 W−1 最后渲染块。
⇒ **W 当月发力对判定无效**；⇒ 入场裸达标、月末被打下 = 挂窗（105 个可判窗里 27.6% 死在这）。
**记：这条是全局最值钱的逆向结论。**

## 工程 / 环境类

### 11. 0-token 幽灵局
陈旧 `career_emu` 实例 MCP 连不上 ⇒ Agent 没有游戏工具 ⇒ `chat.send` 静默完成 ⇒ **LLM 一次都没被调用，分数是无效回声**。
**记：看到 `token_usage=0` 先查实例，别改策略。**

### 12. 上下文累积到 ~99k ⇒ 崩
AgentServer 内部错误 / `keepalive ping timeout`（play23 跑到第 15 月就崩）。
**记：信封 60K 是硬墙，SKILL 必须分层。**

### 13. 端口会漂
`19092` 写死过，实测跑到 `20092`，三次 `engine FAILED`。
**记：`engine FAILED` 先 grep 端口，再改等待窗口。**

### 14. 强杀引擎 ⇒ 数据库只读
`attempt to write a readonly database` 卡死在第 39 月。
**记：别用强杀，用 stop 脚本。**

### 15. 后台进程活不过 19 分钟
`run_in_background`、`nohup &`、`CREATE_BREAKAWAY_FROM_JOB`、`DETACHED_PROCESS` **全都不行**（只有 Windows 计划任务可用）。
计划任务下 stdout 句柄 ⇒ Python 默认 GBK ⇒ `print('\ufffd')` 抛 `UnicodeEncodeError`。
**记：`PYTHONIOENCODING=utf-8` + `PYTHONUTF8=1`。**

## 方法论类（同上一条清单，但更该记）

### 16. 归因 n=1 不许定论
见 [08 战役 F](08-关键战役复盘.md#战役-fr5-的-7829-vs-r8r9-的-613-----我们没有给出结论)。

### 17. 「validate 3/3」不等于能交
它只查三项格式。**真正的判 0 不在这三项里**（32% 的队就死在它查不到的那些）。

### 18. 过拟合审计自动层有盲区
逐字 → 8-gram → 人工形态，三层缺一不可；而且 **`r6` 说"零 dev"的时候，其实还有 8 处**。

### 19. README 自述数字必须回填
「改动 SKILL.md 的版本，打包前必须重跑 README 自述数字 vs 实测比对」——**同一个坑踩了两次**（qe22、qe24）。

### 20. 同一个坑的"伪解法"
`run_game_v70.sh` 里的 pythonw 脱离终端加固 —— 后来发现 **runner 崩溃的真因是 `int(choice)` 的 TypeError**，加固解决的是个伪问题（无害，但不对症）。
**记：加固之前先定位，别把"看着像"当"就是"。**
