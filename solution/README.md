## 设计要点速览（引擎 1.0.1 口径）

- **带宽钳制是全局约束**：每级对 S/O/N 设 `cap = int(门槛(L→L+1) × 1.2)`（即"本级自己的晋升门槛"＝"下一级的准入门槛"，两种说法是同一个数；D、H 不钳），结算后强制钳回 → **到 cap 后一切增量蒸发，晋升是唯一解锁手段**。
- **停手线不是 cap，是 `eff = min(cap, 评分饱和线)`**：终局分只认 **S 120 / N 60**（O 不进终局分）⇒ L5 的 cap 156 里有 36 点是空气、L6 的 204 里有 84 点。**推 S 过 120 = 纯浪费**（唯一例外：L6/L7 的 S 门槛 170/210 高于饱和线，门槛缺口仍要看）。
- **安全垫只有 0.2×门槛**：`cap − 门槛` = L1 **1/0/0**、L2 3/1/1、L3 7/2/3、L4 18/4/6、L5 26/6/9 ⇒ **"顶满 cap"=刚好踩线**，且钳制**只降不升** → 被事件打掉必须主动补回。**L1 的 O/N 安全垫为 0，是全程最脆弱段**。（O/N 安全垫在 L1–L3 **全档为 0~3 点**；其中**不可回补档**（`垫 ≤2`，即 L1/L2 的 O/N 与 L3 的 O）为 **0~2 点**——两个口径适用域不同，见 `design/model_ledger.md` §1 #5。）
- **首年 mercy 兜底有边界**：`current_month ≤ 12` 且 perf<4 会先抬到 4，但后续 bad 谈话还能使 perf−2，故 M6/M12 的 perf 门**仍可能挂**；具体按主 Skill §5.1b 和调度 Skill §5.2 判断。
- **爆雷是全场最大单点损失**：`R≥5` 触发 `risk_burst`，**hp=2**——第一次 R 归零 + **O 回滚到 6 月前快照** + D−2 + W−2，且风险维 `cumulative_risk_inverted = 5×爆雷次数 + R` → **爆 1 次该维永久打 5 折（−5.0 分），`burst_count` 永不复位**；**第二次直接淘汰**。
- **门槛全是 `>=`，卡线能过**：不存在"贴线判负"；真正的挂窗死因只有硬指标缺口 / D 不足（`D≤1` 连续 3 月）/ `duration_in_level < 6`。
- **H+D 是结算线不是底线**：按**最终值**结算，中前期掉点随时能补；把它当底线会误杀大量更优选项（三局 419 决策点回放实测折损 51.5 分）。月 44 起才升级为一票优先。
- **能量必须为窗口前月预留**：每 3 个月发 3E（`1E = 门槛维 +1`，`技能学习` 花 2E）；窗口月 W 的判定在 W 月初、读 **W−1 月末**，而**上一次发能量是 W−3** ⇒ 每次领 3E 须先划 **2E 作下一窗口保险金**。
- **W 没有主动作来源**：= 月薪(level) + 半年奖金(perf 档) + 事件选项。治 W 的药在晋升链上，不在 W 本身。
