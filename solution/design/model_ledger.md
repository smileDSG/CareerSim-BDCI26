## 0. 先纠正一个误解：不是「加模型」，是「给已有机制命名」

三层里最容易做错的是把「数学模型层」理解成**再往策略里塞新公式**。实际相反：

| 看法 | 事实 |
|---|---|
| 「要引入管理学模型」 | 现网的 §2.2c 目标维、§2.2b 总账、§5.4 缺口预算、§3 红线 **已经就是** TOC / 库存论 / CCPM / VaR —— 只是从没写过它们的名字 |
| 「加模型 = 提分」 | 台账已记「加判据 ≠ 提分」（`packaging-discipline.md` §5q–§5r）。**贴名不改任何判据数值**，它买的是**一致性**，不是新能力 |
| 「先补缺的公式」 | 先贴名（零风险）再补形式（中风险、会改行为）。顺序反了会把「一致性收益」和「行为改动」混在一批里，测不出是哪个起作用 |

**为什么贴名能减少漂移**：模型名是一个**压缩的调用指令**。没有名字时，agent 每次遇到门槛维都要从「门槛 / cap / eff / 安全垫 / 率*」重新推一遍该投谁；有名字时它直接调「(s,S) 再订货点：余量 ≤0 就补」——同一结论，但**推导步数从 5 步降到 1 步**，出错面随之缩小。

| # | 缺什么 | 现状 | 该补的形式 | 风险 |

| 4 | **VaR 的期望损失形式** | R 只有 `+1 = −1 分` 的单价 | `E[L] = p(爆雷) × 17 分`，用来比「冒一次雷 vs 少升一级（−3 分）」 | 低 |
| 5 | **敏感性分析** | 无 | 算 `安全垫 = cap − 门槛` 最小的维 = **最脆维**，先加固（等价于库存论里的「最紧约束」） | 低 |

## 4. 人格层 = 模型使用者的职业操守（3 条纪律）

人格不该是角色故事，而该是**纪律**。三条，每条都直接挂在一个已存在的评分机制上：

| # | 纪律 | 挂靠的机制 |
|---|---|---|
| ① | **先调模型再听叙事** —— 模型出结果就执行，不用「现实更合理」推翻 | §2.3c `MATCH: EXACT` ⇒ 语义分析一律 OFF |
| ② | **模型输入缺失就用保守值** —— R 按最坏（`R+1`）、未收录按门槛维 `−1` | §2.3b 未收录兜底 |
| ③ | **每步留痕 CAP-SNAP** —— 模型可审计（六数 ＋ 目标维 ＋ 选项号） | §2.2c ③ 防幻觉 |

**为什么这三条安全**：全部是**禁令 / 纪律**，与 §3 红线同向，因此不会产生与 `argmax` 冲突的动作偏好。

**反例（必须避免的写法）**：写成「我是勇于挑战的职场精英」⇒ 与 §3 红线（`R≥1` 排雷、带风险意象的选项一律不选、`high_intensity_work` 永不选）**对撞** ⇒ 人格从「抗漂移」变成「主动误判」。这与「附录 F 硬编码事件名在 Test 上主动误判」是同一类错误。
