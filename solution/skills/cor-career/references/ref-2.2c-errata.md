#### ③ 到 cap 即停「硬闸」（**对治"顶了 cap 还继续囤 S"——这是本节最硬的一条**）

```text
🚫 硬闸：任何维 **≥ eff**（= min(本级 cap, 评分饱和线)；账本写作 `S 120/120[满]`）→ 该维的 +X **一律按 0 计价**，并且：
   ⚠️ **例外（v48）＝贴线门槛维（阶梯 0.5 命中者）**：它们同样 ≥ eff，但**不按 0 记** —— 见下方 🔴 门槛维例外（按 §1 价格表门票价计）。

   🔴 **门槛维例外（v28b；**v57b 收口为单一条件**）**：某维 **≥ eff 且 `现值 < 下一级门槛`**（L5 的 S：eff 120 < 门槛 130 —— 即「已过停手线、但还没到下一级门票」）→ **其 +X 不记 0**，
      改按 ② 的 `率*_v = (门槛−现值) ÷ 门槛` 处理（门票价：+1 = +3÷缺口），与 a 档同权、可作目标维（v48 扩范围）。
      🔴 **v57b 删除的旧分支（禁止加回）**：旧文在此并列过「**或该维 = 贴线门槛维（它 ≥ eff 且 ≥ 下一级门槛，但 `余量 ≤ 2` 且 `垫 ≤ 2`）**」。该分支**从出生起就只会除零或算出负分** —— 门票价是 `+3 ÷ 缺口`、`缺口 = 门槛 − 现值`，而它硬要求 `现值 ≥ 门槛` ⇒ **分母恒 ≤ 0**。实测它覆盖 L1 的 S/O（现值只能到 cap 9/3 ⇒ 缺口 −1/0）、L2 的 O/N（cap 6/7 ⇒ 缺口 −1/−1）、L3 的 O（cap 16 ⇒ 缺口 −2）—— **无一例外全落在病态区**。
      ⚠️ 且 v57 把「贴线」定义放宽为「只看余量」后，该分支若跟着放宽，还会吞进 **L5/L6 的 S**（垫 26/34、现值 130~132 / 170~172）⇒ 全库 **185 手**落入「缺口 0 或负」的分歧域，机械代入得 0 或 **−3 分**。而这类维**已达标、且现值已超饱和线（S 120）**，+X 对晋升与终局分**双向无价值** ⇒ **唯一正确的计价就是 0**。
      ⇒ **统一口径：`现值 ≥ 门槛` 的维，无论垫多厚、无论是否被阶梯 0.5 判为贴线门槛维，其 +X 一律按上一条硬闸记 0。** 阶梯 0.5 的贴线身份**只用于「回顶优先」与「W−1 末手硬保护」，不再影响计价。**
      ⚠️ 少了本条**第一句**会出现「② 把 S 判成目标维、③ 又把 S 的增益记 0」的自相矛盾（play49 M41 版本）—— 那正是 `现值 < 门槛` 的情形，**仍被本条覆盖**。

   若某选项/动作的【唯一正增益】落在已满维上 → **禁选**，必须改选「正增益落在未满维」的那一项
   若同层【所有】选项的唯一正增益都在已满维上 → 才轮到 H/D → W+ → 最低代价项
   🔁 **贴线维补缺优先检（v50）**：当某门槛维**现值 < 门槛**时，必须**先**在候选中找「该维 +X ≥ 缺口」的项 —— 找到就直接取（按 §1 价格表门票价计价），**不再进入「哪个选项不扣该维」的比较**；只有全部候选都不带该维正增益时，才退回「择不扣者」。
      🔴 **v57c 口径（「候选」=本手的候选）**：上句的「候选」**只指当前这一手屏幕上的可选项**，**不含**该选项后续的「⤷」层级，也**不含**「下一层也许有 +X」的预期 —— 多段事件的层级**按月推进**，把增益记到下一层＝**赌跨月**。⇒ **本手找不到 `+X ≥ 缺口` 就当场按「择不扣者」处理，不得以「层2 会补」为由放行**（单局挂窗即此路径；附录F 范例 6 已加时标警示）。
      🔴 **v54 前提（否则本条就是「以维换维」的后门）**：本条**只在被补的这一维是「唯一未达门槛维」时成立**。
         若同时有 **≥2 个**维未达门槛（如 L3 的 O 与 N 都 < 门槛）⇒ **本条作废**：
         先回 §2.2c ② a 档按 `率*_v` 定**缺口率最大**的那一维；
         且**取项时不许踩另一个欠账维** —— `O+3 / N−2` 这类「补一个欠账维、踩另一个欠账维」的项**一律删除**，
         哪怕它正好把目标维补到门槛（离线回放中此路径的真实走法：它以为「A 档找 +O≥缺口」就够，没看 N−2）。
      ❌ 反面教材（依据为本地离线回放；**本文件不转录**事件名／选项原文／实测数值 —— 这不改变逐维复核与必写痕迹要求）：某局早期，某门槛维已跌到贴线，屏幕上**本手就有一个对该维为正向的候选（纯赚、无负向项）**，它却选了另一个只做「避扣」的项，痕迹行只写「贴线危急,避 X−」——**只做了「避扣」检查、没做「能补」检查**，把唯一能回顶的选项放掉。

✅ 多正增益选项照常用：`S+2 O+2` 在 S 已满 / O 未满时 → 按 **O+2** 计价，**照选，且通常就是最优**
🚫 但 `S+2 O−1` 在 S 已满 / O 未满时 → 记 **O−1**（S 那部分是空气）→ **净负，跳过**
🔵 **`S ≥ 120` **且** `S ≥ 下一级门槛` 后的择优次序（v60 修订版）**：**第 0 位永远是 `dR < 0`**（全表最高单价）；其余按 **`eff` 折算的净收益**取最大者（S 那部分按 0 算）；**只有「全部非 S 增益对 `eff` 均为 0 且 `dR ≥ 0`」的项才降为备选**。⚠️ **`S < 下一级门槛` 时本条不生效**（a 档门票优先于一切 O/N/W 复用）。判据、边界与实证**唯一出处见 §2.2c ① 表末 v60 段**。
```

#### ⑤ 达标保障：能量必须为「窗口前月」预留（**"能不能真到 cap"的物理约束**）

> ⚠️ **本条是独立条款，可单独裁掉**（其余四条与它无耦合）。它是 2026-09-19 从四局 jsonl 原文 + 引擎配置实测得出的。

**引擎配置真源**（`initialization_n_regular/energy_event.data`）：能量**每季度 3E**（M3/M6/M9/…），
`quarter_energy_remaining` **每季重置为 3、不累计**。

**⚠️ 每个维度「1E 换多少点」不一样（2026-09-19 源码级更正，此前写错）**：

| 体力动作 | 花费 | 增益 |
|---|---:|---|
| `prepare_report_material` 准备汇报材料 | **1E** | **O +1**（附 D +1）|
| `network_maintenance` 人脉维护 | **1E** | **N +1**（附 D +1）|
| `skill_learning` 技能学习 | **2E** | **S +1**（代价 H −1）|

⇒ **1E = O/N +1 点；但 S 要 2E 才 +1 点。** 一季 3E 的物理上限 = **S 最多 +1**（或 O/N 最多 +3）。
⇒ **保险金要按「E」预留，不能按「点」算**：2E 保险金 = **O+2 或 N+2 或 S+1**（不是"2 点任意维"）。
（旧版此处写「1E = 任一门槛维 +1 点」是**错的**，会把 S 的窗口修复能力高估一倍——已改。）
⇒ **3E = 3 次独立动作**：每 1E 各调一次 `take_action`（一次只提交一个动作，**别在一条 notes 里塞三个动作、也别反复"再想想"而不提交** —— 空转整季 = 白丢一季，还可能撞 `max_continuations` 直接废掉本局）。

**关键时序**：**窗口月 W 的判定在 W 月初、读 W−1 月末状态；而前一次发能量是 W−3，W 自己那份发在判定之后 = 救不了。**
⇒ **要在 W−1 月手上还有能量补维，只能在 W−3 那次预留。**

> 🚨 **【判定时刻铁律】第二十六轮（源码 + play45/47 双局实证）——「W−1 月末」的精确含义**（v26-①）
> - **源码链**：`game.py:235-240`（剧情选择触发 `resolver.start_new_month()` → `_on_month_advanced()`）与 `game.py:600-606`（季末主行动同理）；`start_new_month` 里 `current_month += 1`、`duration_in_level += 1`（events.py:261-262）；`_on_month_advanced` 顺序 = update_derived_stats → talk → salary → **promotion.apply()** → 清半年调整。
> - ⇒ **判定读的是「触发月度推进的那一次选择结算之后」的状态（含该选择自身的增减），不是推进前的状态。** 即：**W−1 月最后一次会推进月份的那个选择（剧情选项 / 主行动），它自身的增减直接算进这次判定。**
> - **双局实证**：play45 M5 末 N=0，触发推进的最后一次选择是「借伞 **N+3**」→ 判定时 N=3 → **过窗**（终局 76.14 / L6）；play47 M5 末 N=3，触发推进的最后一次选择是长链 #7 首层「次日上班再回 **N−1**」→ 判定时 N=2 → **挂窗**（终局 69.50 / L5）。**两局唯一差异就是这最后一步的符号。**
> - ⇒ **操作含义**：**W−1 月的最后一步 = 本窗口真正的最后一道闸**，必须按「门槛禁跌律（缓冲量判据）」（§2.2c ⑥、§2.4d 用法 8、cor-window §5.2）再核一遍，**哪怕它只是一个长链首层**。

**四局实测（2 过 2 挂）**：四局 M5 全部 **E0**（M3 领的 3E 全在 M3 花光，其中 2E 喂了 H）：
p40/p41 的 M4/M5 事件恰好没碰 O/N → M6 过；**p42/p43 被事件把 O 打到 1，手上一分能量都没有、修不回 → M6 挂 → 首升拖到 M12**。
p43 的笔记原文自证：`O将由3降到1…需在M6窗口前补回O` —— 它**知道**要补，但没有能量可补。

```text
铁律：每次领到 3E，先划出 2E 作为「下一个窗口的保险金」——
  · 仅当某一门槛维 ≤ 本级门槛（= **临窗余量律的「余量 ≤ 0」**）时才允许动用（此时它压过一切，但 R≥1 排雷仍排在它前面；**窗口期内若它是唯一缺口且为 S（2E 价）→ §4.3 0a 门槛维优先例外生效**）
  · 优先补 μ 最大的那一维
  · 禁止把这 2E 花在 H/D 上（唯一例外：H ≤ 6 —— H 是 hp，低于 6 才算安全线告急）

```

> 📌 **与 cor-window §4.3 的衔接**：cor-window §4.3 能量阶梯的 `1) R≥1 先占 2E` **优先级最高，不受本条约束**（**唯一例外 = §4.3 0a「门槛维优先」**：窗口期内唯一门槛维为 S 时先划 2E）；
