## 4.3 执行配比（状态驱动，按账本，不写死）〔触发〕

> **M6 专用状态机（L1→L2，M3–M5）**：本状态机优先覆盖本节通用窗口期主行动配比，但不覆盖红线、`H≤3`、L1/L2 零垫门槛保护，也不允许忽略跌破门槛后的回顶。M3 月末先确保 `S≥9/O≥3/N≥3`，其中 `O≥3` 是不可延期门票；`O<3` 时主行动锁 `apply_key_project`，每个可用 1E 优先 `prepare_report_material`。达到 `9/3/3` 后，M4–M5 停止主动追求额外三维收益，优先不增风险、保 D/H、保住门槛的低风险事件；若任一门槛维跌破门槛，立即恢复对应回顶动作。`O<3` 为强制补 O，`O=3` 为卡线保护，只有 `O≥4` 且 `S/N` 已达目标时才允许停止主动补 O。若 `R≥3`，任何 `dR≥+2` 的选项直接删除，即使带 `N+1/O+1`；通用 `R≥1` 风险否决、`R≥2 → lay_low`、红线、`H≤3`、门槛维负值仍按各自更高优先级处理。该状态机只适用于 M6，不得套用 M12/M18 的 L3 动态预算。

**主行动（每季 1 个）**：🚨 **第十轮的固定维序（O→N→S）已废除**——play40 实证：O 几乎永远 <cap，固定 O 优先把 `build_mentorship` 锁死成 **16 个主行动 0 次** → 终局 N=56（差 4 分满分，−0.67 分）且 perf 短板被 N 卡住。新判据 = **主技能 §2.2c 的目标维（缺额比 μ 最大）** ＋ **§5.4 的补缺压力 P（判断本窗还救不救得回来）**：

- ① 若 R ≥ 2 → `lay_low`（免费 R-1）：与能量事件 `defuse_legacy_risk`(2E,R-1) 配合 = 本季 R-2，最快清零。**安全永远第一，此条不受预算制约束。**
- ② elif **窗口前 ≤3 个月（W−3 起）且 O ≤ 本级门槛**（🔴 v33：原写 `cap`，已改为门槛；🔴 v34-stab：**再进一格，`<` 改 `≤`** → **O 恰好 = 门槛（余量 0）也触发**，仅 `O ≥ 门槛+1` 时本条不触发；依据＝O 中位余量 0.0、险区占比 36%，30 次决定性窗口观察里 18 次（60%）最紧一维是 O）→ `apply_key_project`（**O 保卫条款强制**：O 掉门槛 = 窗口黄 + perf 崩，见 §5.2）
  - ⚠️ **v33 实证（v32 M27）**：旧条款在 `O=23 > 门槛22` 时仍强制 `apply_key_project`(S+1) 顶掉 `apply_rotation`(S+2) → **白丢 1 S**，而当时 O 已有 +1 缓冲、cap 是评分停手线不是关卡线
- ③ elif 存在未顶 cap 的维度 → **按主技能 §2.2c ② 算出「目标维」（缺额比 μ 最大，并列 N>O>S）**，对位主行动：**目标维 = S → `apply_rotation` · = O → `apply_key_project` · = N → `build_mentorship`**

- ⑤ elif 三维全顶 cap 且 H+D=20 → `apply_rotation`（三维全是空气，选无害项等下一窗口解锁带宽；**禁止选会埋雷的**）

- 🧊 **自走维冻结闸（2026-09-19 五局样本实证；新增，硬约束）**：每季分配前先按 **主技能 §2.2c ② 第 1.5 步**
  算两件事——`λ_v`（本维**事件自给**的实测月均斜率）与 `F_v = 现值 + λ_v × 剩余月数`。然后：
  **`F_v ≥ eff_v` 或 `P_v > 1.0` 的维，本季一个槽位都不投**（剧情槽 / 主行动 / 体力，含免费主行动）；
  省下的资源全部转给 `F_v < 门槛` 的维。理由：前者自己会长到饱和线（投进去全被 cap 钳掉），后者本窗物理填不满。
  🔴 **门槛维豁免（v28b · 必读）**：**`现值 < 下一级门槛` 的维不适用本闸** —— 它自走到 eff 也补不上门槛

     ⚠️ 否则 L5 的 S（123 < 门槛 130）会被本闸先剔掉，**主技能刚加的 率*_v 修复当场失效**（play49 M41 原样复现）。
